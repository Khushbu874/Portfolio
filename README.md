### 3. 🤟 **SILENT TALK AI** — *3D Avatar & Sign AI Architecture (2025)*
- **Description**: A 3-module 3D Sign Language HCI platform: Learn (3D avatar simulations), Convert (Text/Voice to 3D signs via ChromaDB <50ms cache & gpt-4o-mini), and Recognize (Webcam sign-to-voice via MediaPipe & TFLite).
- **Tech Stack**: FastAPI, Three.js, MediaPipe JS, TensorFlow Lite, ChromaDB, OpenAI gpt-4o-mini, Gemini NLP, Web Speech API
- **Problem**: Communication barriers between sign language users and non-signers due to lack of accessible sign recognition and 3D gesture translation.
- **Solution**: 3-Module System:
  1. **Learn**: 3D avatar GLTF bone simulations using Three.js.
  2. **Convert**: Speech API with ChromaDB vector caching (<50ms HIT) & gpt-4o-mini fallback.
  3. **Recognize**: Webcam MediaPipe 3D bone tracking, TFLite local inference, Gemini NLP sentence synthesis, and Web Speech TTS.
- **Metrics**: <50ms Cache Lookup \| ≥95% Cache Precision \| 3 Modules + FastAPI Gateway
- **Links**: [GitHub Repository](https://github.com/Khushbu874/SilentTalk)
